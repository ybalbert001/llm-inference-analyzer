# Validate Experiments / 实测验证数据

This directory holds **empirical validation data**: real deployment measurements (e.g. actual VRAM usage reported by SGLang/vLLM on GPUs) to be compared against the analyzer's theoretical estimates.

本目录用于存放**实测验证数据**：真实部署环境下的测量结果（例如 SGLang/vLLM 在 GPU 上实际报告的显存占用），用于与本工具的理论估算值对照。

Currently empty — data will be added as experiments are run.

目前为空，实验完成后会陆续补充。
